- [x] **T1 percentages right-aligned (owner request).** Every percentage the pane prints in a column (context, 5h,
  7d, pace) is padded to the same cell width, so ` 87%`, `  7%` and `100%` align (4 cells). Verify: format test, `pctCell(7)` = `  7%`,
  `pctCell(100)` = `100%`; pane tests, credit rows with 87 and 7, and with 100 and 87, end at the same column.
- [x] **T2 percentage before the period (K2).** Credit row text `63% 5h ↻ 2h10m`. Verify: pane test on the row text.
- [x] **T3 reset clock time (K7).** After the countdown, the local reset time: `(14:30)` within 24 h, `(dom 09:00)`
  beyond. Verify: format test with a fixed `now` and time zone-independent input.
- [x] **T4 burn rate and exhaustion (K7).** The mod keeps the 5h `percentUsed` samples of the last 30 min in state;
  with ≥ 10 min of samples a line under the 5h row: `−9%/h · finisce tra 6h50: arrivi al reset` (green), or
  `−31%/h · finisce tra 1h40, prima del reset` (red) when exhaustion comes before the reset; no line with fewer
  samples or a non-positive rate. Verify: format test of the pure rate/eta function (samples → rate, eta, verdict);
  pane test for both colours and for the absent line.
- [x] **T5 cache share of the last main turn (K6).** From the last main-loop `turn.complete` usage:
  `cache_read / (input + cache_read + cache_creation)`, right of the CONTESTO title (`cache 94%`). Absent before the
  first turn. Verify: pane test.
- [x] **T6 ALM line (N4).** Under the folder row: `ALM <org> / <project> · <identity>` resolved for the cwd from
  `~/.claude/workspaces.json` with the same rules as `hooks/lib/workspaces.js` (reuse it if the mod can import it,
  else a pure port with the same tests); `ALM non mappato` in red when nothing matches. Verify: format test on a
  sample workspaces object (nested root, plain root, unmapped).
