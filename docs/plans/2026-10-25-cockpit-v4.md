# Cockpit v4 — what is happening, what happened, how it is going, what looks wrong

Goal: the pane answers four questions about the current session at zero model-token cost. Everything is
computed locally from harness events; no hook injects context or calls the model, except the two
user-pressed footer buttons.

## Decisions (owner, 2026-10-25)

- Header and status line keep today's essentials unchanged: model, effort, cost, context, credits left,
  folder and branch. The status line stays silent while the pane is open (unchanged).
- Status line gains ONE thing: a `⚠ <n>` signals badge when the pane is closed and n > 0.
- Tabs, text labels (no icon-only labels): **Ora · Segnali · Cronologia · Costi · Lavoro · Note**.
- System tab removed: no CPU / RAM / network / disk. Orphan processes and ports move to Lavoro.
- PRs, tasks, work items: a clickable link only, no state, no checks, no reviews.
- Note stays its own tab; multiline handling must be robust (see task 6).
- `log hours` leaves the global footer: Lavoro tab only, behind a confirm.

## Tasks

1. **Events that really arrive (#32).** A managed `prepend` plugin forwards `skill.prompt`,
   `classic.SubagentStop`, `classic.PermissionRequest`, `classic.Notification`, `classic.Stop` past the
   `user` tier, so cockpit never sees them. Derive the same data from events that do arrive: skills from
   `tool.call` with tool `Skill`; waiting-for-permission from `tool.check` (await `next(e)`; decision `ask`
   with a person approver → waiting until that call resolves; swallow every error, it is a gating event);
   workflow name from `agent.spawn` `e.workflow`. Remove handlers that can never fire. Test: a fixture
   world where those classic events are never dispatched still yields skills and waiting state.
   Verify: `claude plugin test mods/cockpit`.
2. **Refresh and render cost (#33).** No refresh tier runs while the pane is closed (heartbeat for the
   status line file only); git refresh only on main-loop `turn.complete`, never on subagent turns; one
   serialisation per store patch; render only the active tab. Test each guard.
3. **Tabs.** Ora (state + waiting seconds, live agents with growing tokens, workflow run: phase, round,
   agents done/total, $ so far, tool call in progress), Cronologia (one row per event: round with $ and
   duration, skill loaded, agent spawned with model and $, compaction, error, hook block, workflow STALL;
   filter by type; bounded ring buffer), Costi ($ per round sparkline + top 3, $ and cache-hit per agent
   and per model, $/h and 5h-credit exhaustion projection, context by category, top 5 outputs that grew
   the context — reset on compaction), Lavoro (branch, perimeter + files outside it, changed files with
   diff on click, PR / task / work item links only, orphan processes and ports, `log hours` with confirm),
   Note (task 6). Remove System and the duplicated branch/commits block.
4. **Segnali.** Local detectors, each row = what, why it matters, what to do:
   subagent > 150k tokens or > 40 % of session $ · Opus on an Explore/read-only agent · tool result
   > 20k chars · same file read ≥ 3 times · same command failed ≥ 2 times · cache-hit < 50 % after an
   idle gap · context +100k in 3 rounds · ≥ 2 done-claim blocks · workflow STALL or round > 3 ·
   permission waiting > 60 s. Thresholds in one constants block. Header badge with the count.
5. **Status line badge.** `statusline.js` reads the signal count from the cockpit state file and shows
   `⚠ <n>` when the pane is closed. Test in `tools/statusline-cockpit.test.mjs`.
6. **Note, multiline.** Shift+Enter / pasted text keeps newlines; CRLF normalised to LF; empty lines and
   leading indentation preserved; long lines wrap by display width (CJK / emoji safe); a long note is
   collapsed with an expand toggle; edit round-trips the exact text; "send to prompt" inserts the exact
   multi-line text; empty or whitespace-only note is not saved; delete asks first; cursor movement across
   lines in the editor. Tests for each case.
7. **Footer.** `compatta` · `analizza suite` (sends `/retro`, confirm first; later `retrospettiva`: last 10 days or this session) · `copia riepilogo` (session
   cost summary into the prompt box, no model call).
8. **Cleanup (#40).** Split `view.tsx`, `work.ts`, `register.tsx` by concern; drop exports with no caller.
